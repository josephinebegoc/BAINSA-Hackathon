Accessible Attention for Excel — Technical Overview

Static frontend plus one Python serverless function, deployed on Vercel.

Architecture

Frontend: plain ES modules, no framework or build step. Backend: one FastAPI function exposing /api/health, /api/upload (multipart .xlsx), /api/explain and /api/overview. No database, no server state — the browser holds the parsed workbook and sends the context each call needs. Dependencies: FastAPI, openpyxl, python-multipart, anthropic.

Extraction

openpyxl opens the workbook twice — data_only=False for formulas, True for cached values and error codes. Each cell keeps its value, formatted display, fill and font colour, bold/italic/underline, borders, comment, number format and error. Header row and label column are inferred; the table is cropped at the first blank row; unresolvable theme colours are recorded as present-but-unnamed rather than guessed.

Attention engine

attention.py: 478 lines of pure functions, no I/O.

CueRule
visualNon-default fill; red or orange font; bold where the row is not; or a column whose number format differs in kind from its series.
anomaly0.6745·|x−median|/MAD > 3.5 and ≥15% from the median. Where MAD/|median| < 0.01 the z-score is meaningless and >40% distance is used instead. Series under 4 numbers are skipped.
trend≥3 consecutive moves one way, then a reversal exceeding 25%.
errorCached Excel error value.

Columns are grouped for comparison by the order of magnitude of their medians (within 100×), judged per column across the sheet so one outlier cannot form a group alone. Number format is deliberately not used: the demo workbook has one revenue column formatted as a percentage and four as General, which would split a twelve-month series into three.

Sonification

Web Audio. The main series fixes one pitch scale, mapping its 5th–95th percentile onto 110–1760 Hz with outliers clamped. A row's median sets a register within that scale; the row's own min–max is stretched across 34% of the range around it. Frequency is exponential in value, so equal steps give equal intervals. Amplitude follows (110/f)0.5 (≈ −3 dB per octave) to offset equal-loudness curves. Notes are 400 ms, panned left to right; errors are a square wave, empty cells silent.

Language model use

Spoken text is generated from deterministic templates built from the engine's findings, and the Anthropic API rephrases them into natural speech under a 5 s timeout. Model output is validated before use: it is rejected in favour of the template if it contains a blocklisted judgement word, markdown, or any digit sequence absent from the input facts, so no spoken sentence can assert a number or an opinion the engine did not produce. Every call has a template path, so speech degrades rather than fails.

Accessibility and tests

speechSynthesis (cancelled before each utterance) and aria-live regions (polite for movement, assertive for cues) for VoiceOver and NVDA. Grid at role="application" so arrow keys pass through browse mode. One earcon for all cue types, played before speech, cue name spoken first; navigator.vibrate feature-detected; markers carry a letter as well as a colour; Atkinson Hyperlegible. 82 Python tests and 27 JavaScript assertions, including a regression test that the engine independently reproduces the shared fixture's cues.
