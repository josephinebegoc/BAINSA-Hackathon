Accessible Attention for Excel

Screen readers make spreadsheet cells readable. We make visual attention accessible.

Press "Load demo" to open the sample sales sheet.

Keyboard shortcuts
  • Arrow keys move one cell
  • O overview of the sheet
  • Space first flagged cell
  • N / Shift+N next / previous flagged cell
  • W or ? why was this cell flagged?
  • D describe everything about this cell
  • R / C read the whole row / column
  • Esc stop speaking
  • H hear these shortcuts
